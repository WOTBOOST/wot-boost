# WOT-BOOST

Готовый статический сайт на HTML/CSS/JavaScript.

## Запуск локально
1. Распакуйте архив.
2. Откройте `index.html` в браузере.

## Изменение цен и услуг
Откройте `script.js` и измените массив `services`.

## Публикация
Можно загрузить файлы на любой статический хостинг:
- GitHub Pages
- Netlify
- Vercel
- обычный хостинг с FTP

После публикации получите постоянный URL и создайте QR-код, ведущий на этот адрес.

## Важно
Отзывы и цены в стартовой версии демонстрационные. Перед публикацией замените их на реальные.
Discord-ссылка пока ведёт на копирование ника, так как для полноценного перехода нужна ссылка-приглашение на сервер.
